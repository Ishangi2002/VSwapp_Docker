# 🚀 SkillSwap – Full-Stack Skill Exchange Platform

SkillSwap is a full-stack web application that enables users to exchange skills, manage profiles, and connect with others based on shared learning interests.  
The platform is developed using **Spring Boot** for the backend, **React.js** for the frontend, and is fully **Dockerized** for consistent deployment.  
The application is hosted on **AWS** and follows modern **DevOps** and **CI/CD** practices.

## 🌟 Project Highlights

- 💻 Full-stack skill exchange platform  
- 🔐 Secure RESTful APIs with CRUD operations  
- 🐳 Dockerized backend and frontend  
- ⚙️ CI/CD and cloud-ready architecture  
- 📈 Scalable, maintainable, and production-oriented design  

## ✨ Features

- 🧑‍💻 User registration and profile management  
- ✏️ Skill creation, updating, and deletion  
- 🤝 Skill exchange and discovery  
- 🌐 REST API-based communication  
- 🐳 Environment-independent deployment using Docker  
- ⚡ CI/CD integration support

## 🐳 Docker Setup

**Prerequisites:**  
- Docker  
- Docker Compose  

**Build and run the application:**  
```bash
docker-compose up --build
```
Docker is used for local development and creating consistent deployment artifacts for cloud hosting.

## ☁️ Deployment

- The application is deployed on **Amazon Web Services (AWS)**
- Backend and frontend are containerized using Docker
- CI/CD pipelines are implemented using Jenkins
- Infrastructure provisioning is managed using Terraform

## 🔄 CI/CD Pipeline Overview

- 📂 Source Control: GitHub
- 🔧 Continuous Integration: Jenkins
- 🐳 Containerization: Docker
- 🏗️ Infrastructure as Code: Terraform
- ☁️ Cloud Platform: AWS
